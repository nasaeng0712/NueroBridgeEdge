# 개발 및 검증 현황

## 목표와 일정

최종 목표는 상상하는 다양한 장면·사물·동작의 실시간 시각화다. 손 모델 제어는 초기 시연 사례이며 최종 범위를 대체하지 않는다.

- 조기 시연: 2026년 12월 둘째 주
- 최종 프로토타입 시연: 2027년 1월 31일
- 후속 장비: NeuroSky MindWave Mobile 2, Orange Pi 5 Plus, DEEPX DX-M1
- 유지할 요구사항: 장비 없는 시뮬레이션, CPU 기반 개발, NPU 경량화·양자화

## 현재 구현

표준 라이브러리 기반 머신 진단 도구와 단위·명령 실행 테스트를 추가했다. 이 도구는 실행한 머신의 사양을 보고한다. 클라우드에서 실행한 결과는 사용자 노트북 사양이 아니다. GPU와 별도 패키지 설치는 필요 없다.

## 검증 범위

- PASS: 클라우드 Linux에서 진단 명령과 테스트 3개 실행
- BLOCKED: 첨부 설계도 미수신에 따른 상세 요구사항·검증 기준 확인
- BLOCKED: 사용자 노트북 사양 미확인에 따른 로컬 환경 확정
- NOT TESTED: Windows/macOS 실기 실행
- NOT TESTED: EEG 수신·해독, 시뮬레이션, 시각화, 실시간 지연·자원 측정
- NOT TESTED: 실제 BCI·Orange Pi·NPU 연결, 양자화 모델 정확도와 성능

설계도 수신 후 요구사항을 추적하고 기능별 구현·실행·시험을 진행한다. EEG 해독 결과, 합성 입력, 사전 정의 명령은 별도로 표시한다. 현재 단계는 전체 시스템 완성이 아니다.

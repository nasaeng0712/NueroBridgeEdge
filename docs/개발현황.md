# 개발 및 검증 현황

## 목표와 일정

최종 목표는 상상하는 다양한 장면·사물·동작의 실시간 시각화다. 손 모델 제어는 초기 시연 사례이며 최종 범위를 대체하지 않는다.

- 조기 시연: 2026년 12월 둘째 주
- 최종 프로토타입 시연: 2027년 1월 31일
- 후속 장비: NeuroSky MindWave Mobile 2, Orange Pi 5 Plus, DEEPX DX-M1
- 유지할 요구사항: 장비 없는 시뮬레이션, CPU 기반 개발, NPU 경량화·양자화

## 현재 구현

표준 라이브러리 기반 머신 진단 도구와 단위·명령 실행 테스트를 추가했다. 이 도구는 실행한 머신의 사양을 보고한다. 클라우드에서 실행한 결과는 사용자 노트북 사양이 아니다. GPU와 별도 패키지 설치는 필요 없다.

## 검증 범위

- PASS: 클라우드 Linux에서 진단 명령과 테스트 3개 실행
- BLOCKED: 첨부 설계도 미수신에 따른 상세 요구사항·검증 기준 확인
- BLOCKED: 사용자 노트북 사양 미확인에 따른 로컬 환경 확정
- NOT TESTED: Windows/macOS 실기 실행
- NOT TESTED: EEG 수신·해독, 시뮬레이션, 시각화, 실시간 지연·자원 측정
- NOT TESTED: 실제 BCI·Orange Pi·NPU 연결, 양자화 모델 정확도와 성능

설계도 수신 후 요구사항을 추적하고 기능별 구현·실행·시험을 진행한다. EEG 해독 결과, 합성 입력, 사전 정의 명령은 별도로 표시한다. 현재 단계는 전체 시스템 완성이 아니다.

## 설계도 수신 후 첫 구현

설계도 v0.8을 원문 보존했다. SHA-256:
`b71444567e6a1a6c5093d2455d9a6222f1175c5d238d779a166889738e6af5f5`

이전의 설계도 미수신 BLOCKED는 해소되었다. 현재 대화의 개발 지시를 구현 작업의 승인 근거로 사용하며, 구매·과금·OS 교체를 승인한 것으로 해석하지 않는다.

- M02: 프레임 길이·체크섬·DataRow·확장 코드 검사, signed RAW, 구간 재설정.
- M03 초기 구현: 합성 transport/EEG 분리, 오프셋·단조 시각·구간 ID, 각 write의 fsync, partial 보존, 정상 종료 해시, 원본 재생 비교.
- PASS: 전체 테스트 13개, 합성 256샘플 기록·해시·재생 일치.
- PASS: 저장 실패 주입 후 파싱 결과 생성과 후속 수신 차단.
- NOT TESTED: 이동 명령 STOP 연동(V10 전체), 전원 장애 복구, 내구성/처리량, 실측 T-02 5분 수신.
- NOT TESTED: M01 Bluetooth 및 M04~M18. 실제 EEG·NPU·3D 성공 증거 없음.

현재 저장 구조는 합성 개발용 단일 세션 파일이며 §06 전체 디렉터리 구조·회전·복구 구현 완료가 아니다. boot_id는 현재 수집 인스턴스 ID로서 실제 운영체제 부팅 ID와의 통합이 필요하다. 원본 데이터는 GitHub 업로드 대상이 아니며, 기준 설계도와 코드만 버전 관리한다.

다음 구현 순서는 저장 예외·종료 복구 강화, 품질·구간별 윈도우, TCP 상태 검증과 안전 정지, 합성 통합 및 Godot 렌더러다. 이후 데이터/실기 접근을 확보하여 학습·양자화·독립 온라인 검증을 진행한다. 임의 임계값으로 LEVEL-2/3 성공을 판정하지 않는다.

문서 BLOCK-01의 온라인 통과값, BLOCK-02의 사용자 주5시간 일정 적합성, BLOCK-03의 시험 전 파라미터 동결은 아직 해소되지 않았다. 소프트웨어 준비 작업을 진행할 수 있지만, 실기 및 최종 합격 판정은 이 항목을 확인해야 한다. 설계도에 실린 외부 라이브러리 코드는 복사하지 않았으며 현재 추가 의존성은 없다.

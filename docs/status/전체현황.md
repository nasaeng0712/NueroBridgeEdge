# 전체 구현 및 검증 현황

이 문서는 단계별 진행 상태의 기준 목록이다. 설계도 원문은 수정하지 않는다.
현재 사용자 지시는 일상적인 단계별 재승인 없이 계속 진행하되, 요구 변경·설계 충돌·필수 검증 실패·중요 미정 결정이 있을 때 중단하는 것이다.

## 현재 중단 사유와 재개 조건

v0.8 §14 순서상 P1 실제 장치 검증이 선행한다. 현재 환경에는 해당 장치의 실행 경로나 사용자 장비 접속 정보가 없다. T-01은 FAIL이 아니라 BLOCKED이며, 합성 CPU 시험으로 대체하지 않는다.

사용자 판단 필요: 실제 장비에서 P1을 먼저 수행할지, 또는 P1 실기 검증은 BLOCKED로 유지하며 장비에 의존하지 않는 후속 소프트웨어 준비를 병행하도록 순서를 조정할지 결정한다. 후자를 선택해도 P1/P2 이후 게이트와 최종 성공 판정은 자동 통과하지 않는다.

## 갱신 규칙

기능 단위 완료마다 구현 파일, 실행 명령, 실제 테스트 결과, 커밋, 미검증 항목을 기록한다. PASS/FAIL/BLOCKED/NOT TESTED를 구분한다. 합성·공개 재생·실측 데이터를 구분하며 LEVEL-0/1을 목표 성공으로 보고하지 않는다. 새 단계 착수 전 선행 검증과 중요한 미정 결정을 확인한다.

# 주요 외부 의존성과 출처

외부 저장소의 소스 파일을 복사하지 않고 공식 패키지/API를 사용한다.

| 항목 | 역할 | 라이선스 | 출처 |
| --- | --- | --- | --- |
| NumPy | CPU 수치 계산·FFT | BSD-3-Clause | https://github.com/numpy/numpy |
| SciPy | 인과 SOS 필터 설계·실행 | BSD-3-Clause | https://github.com/scipy/scipy |
| Godot Engine | 객체와 분리된 3D 장면 | MIT | https://github.com/godotengine/godot |

패키지나 엔진 재배포 시 동봉 라이선스·서드파티 고지를 보존한다. 설치된 버전은 실행 기록에 남기며, 라이선스가 장치 호환성·성능을 보장하는 것은 아니다. DEEPX 도구와 NeuroSky 프로토콜은 설계도 출처를 따르되 실제 SDK·장치 검증은 별도 보류한다. 유료 에셋은 사용하지 않는다.

| ONNX | 모델 형식·checker | Apache-2.0 | https://github.com/onnx/onnx |
| ONNX Runtime | CPU 모델 출력 정합 | MIT | https://github.com/microsoft/onnxruntime |

ONNX 1.23.2와 ONNX Runtime 1.31.1을 프로젝트 가상환경에 설치해 시험했다. 현재 학습기는 NumPy 소형 MLP이며 PyTorch·GPU는 필수가 아니다. DX-COM/DX-RT SDK는 설치·실행하지 않았다.
